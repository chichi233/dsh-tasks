## 两列模型（图的骨架）

**rail（左侧栏，5 组）→ B 栏（列表 / 四象限 / 习惯卡片 / 该日任务）→ C 栏（任务详情 / 习惯详情）**，中间区放日历、番茄钟、螺旋工作法、设置这类全宽工具页。

## 架构图上三个结构性事实

1. **L1 只有一个真源**：`localStorage['dsh.tasks.v1']`，全量写回；关页前 `beforeunload` 落盘。
2. **L3 提醒只能页面内跑**：`setInterval` 轮询 + 音频 beep，页面关掉就没有进程。所以「到点提醒」在最坏情况下会漏，这是架构决定，不是 bug；补它要动宿主能力，超出本插件范围。
3. **L3 里两个引擎争同一个中间区**：螺旋与番茄互斥（启动螺旋先暂停番茄，另一侧按钮置灰），结论见 `ui-spec-stage2.md §4.10.8`，不是实现偷懒。

## 图上几处容易看错的地方

- **四象限四色同源**：格左边线与标题色都取 `--dt-quad`，值来自 `QUAD_COLORS`（`00-prelude.js:112-117`）：Q1 红 / Q2 黄 / Q3 蓝 / Q4 主文本色（不上色）。
- **日历四模式**：新历 / 农历 / 节气 / 节假日，三点菜单切换；副行优先级「节假日 > 节气 > 农历」，同日只显示节日。
- **习惯 C 栏三数字**：当前连续 / 最长 / 本月 N 次，配 42 格热力图（周一起始、可点击补打卡）。
- **番茄节奏三选一**：完成后暂停 / 跳过休息 / 自动休息——节奏只决定段落怎么衔接，不改任何时长。

## 已知缺口

- 图上「部分」五处 + 「无」一处就是当前欠账，其中子任务（`parentId` 有数据、UI 零渲染）是唯一「无」，属数据黑洞，需产品拍板做或明确删。
- 覆盖度是静态对照，不等于真机可用：本图不对任何一条背书为零缺陷，真机结论见 `docs/acceptance-stage2.md`。
- 提醒「部分」的根因是架构（页面内定时器），不是实现遗漏，图上已在 L3 写明。

## 行号说明

所有 `文件:行号` 对应 `src/parts/*.js` 当前版本，分节写法为 `/* ----- 分节 ----- */`。行号会随实现漂移，**行号只是定位提示，不是判据**——判断某能力是否存在，用静态 grep 的监听集合/字段集合，不要只认行号。已知漂移历史见 `docs/doc-drift-audit.md`。

## 与 teardown 对照表的差异
